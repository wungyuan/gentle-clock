Gentle Clock Support

Questions or suggestions? Email evanywung@gmail.com, or use Alarms → ⋯ → About → Feedback & Suggestions in the app.

My alarm didn’t ring

Make sure alarms are allowed in Settings → Apps → Gentle Clock, and check the alarm volume in Settings → Sounds & Haptics. If Ring Until Stopped is off, the sound plays only for the length you set.

How do sunrise alarms work?

They follow your local sunrise or sunset every day. Allow location or choose a city in Alarms → ⋯ → Location.

How do I restore my purchase?

Open Alarms → ⋯ → About → Restore Purchases, signed in with the same Apple Account.

How do I cancel the yearly subscription?

Settings → Apple Account → Subscriptions → Gentle Clock.

Privacy Policy

温柔时钟 技术支持

有问题或建议，请发邮件到 evanywung@gmail.com， 或在 App 里点「闹钟 → ⋯ → 关于 → 反馈与建议」。

闹钟没有响

请确认「设置 → App → 温柔时钟」里允许了闹钟，并在「设置 → 声音与触感」里检查闹钟音量。 关闭「确保唤醒」时，铃声只响你设定的时长。

日出闹钟怎么用？

它每天跟着当地的日出或日落时间调整。请允许使用位置，或在「闹钟 → ⋯ → 位置」里选择城市。

怎么恢复购买？

用同一个 Apple 账户登录，打开「闹钟 → ⋯ → 关于 → 恢复购买」。

怎么取消年订阅？

「设置 → Apple 账户 → 订阅 → 温柔时钟」。

隐私政策

溫柔時鐘 技術支援

有問題或建議，請寄信到 evanywung@gmail.com， 或在 App 裡點「鬧鐘 → ⋯ → 關於 → 意見回饋」。

鬧鐘沒有響

請確認「設定 → App → 溫柔時鐘」裡允許了鬧鐘，並在「設定 → 聲音與觸覺」裡檢查鬧鐘音量。 關閉「確保喚醒」時，鈴聲只響你設定的時長。

日出鬧鐘怎麼用？

它每天跟著當地的日出或日落時間調整。請允許使用位置，或在「鬧鐘 → ⋯ → 位置」裡選擇城市。

怎麼回復購買？

用同一個 Apple 帳號登入，打開「鬧鐘 → ⋯ → 關於 → 回復購買」。

怎麼取消年訂閱？

「設定 → Apple 帳號 → 訂閱項目 → 溫柔時鐘」。

隱私權政策

やさしい時計 サポート

ご質問・ご要望は evanywung@gmail.com までメールでお送りいただくか、 Appの「アラーム → ⋯ → 情報 → ご意見・ご要望」からどうぞ。

アラームが鳴らなかった

「設定 → App → やさしい時計」でアラームが許可されているか、「設定 → サウンドと触覚」でアラーム音量を確認してください。 「止めるまで鳴らす」がオフのときは、設定した長さだけ鳴ります。

日の出アラームの使い方

毎日その土地の日の出・日の入りに合わせて調整されます。位置情報を許可するか、「アラーム → ⋯ → 位置情報」で都市を選んでください。

購入を復元するには

同じAppleアカウントでサインインし、「アラーム → ⋯ → 情報 → 購入を復元」を開いてください。

年間プランを解約するには

「設定 → Appleアカウント → サブスクリプション → やさしい時計」から解約できます。
